    القياس

    بيكسلات الإعلانات — لإعادة استهداف من قرأ الدليل

    التحقّق من ملكية الموقع

    من أين أجد هذه المعرّفات؟
    1. Google Analytics 4: analytics.google.com ← الإدارة ← مصادر البيانات ← الويب ← «معرّف القياس» (يبدأ بـ G-). إن لم تكن لك خاصية: أنشئها بموقع https://guide.ssouq.com.
    2. Search Console: search.google.com/search-console ← إضافة موقع ← «بادئة عنوان URL» ← https://guide.ssouq.com/ ← طريقة «علامة HTML» ← انسخ الوسم هنا واحفظ، ثم اضغط «تحقّق» هناك.
    3. Bing: bing.com/webmasters ← أسهل طريق «استيراد من Google Search Console» (بعد تحقّق جوجل) فلا تحتاج وسمًا؛ وإلا طريقة «HTML Meta Tag».
    4. Clarity: clarity.microsoft.com ← مشروع جديد ← الإعدادات ← «Project ID».
    5. البيكسلات: من مدير إعلانات كلّ منصة (Snap Ads Manager · TikTok Events Manager · Meta Events Manager) ← معرّف البيكسل. تُسجّل زيارة كل صفحة (PageView) لتبني منها جمهورًا تعيد استهدافه.

    ربط Google Analytics وSearch Console بهذه الصفحة

    اختياري: لعرض أرقام جوجل داخل هذه الصفحة، ويحتاج ملف مفتاح حساب الخدمة. أمّا وسم Google Analytics على الدليل فمعرّفه (G-…) في حقل «Google Analytics 4 — معرّف القياس» أعلاه.

    خطوات الربط (مرة واحدة، دقائق)
    1. مشروع في Google Cloud: أنشئ مشروعًا (أي اسم).
    2. فعّل الواجهات: Google Analytics Data API · Google Search Console API · Google Analytics Admin API (ليظهر رقم الخاصية وحده).
    3. حساب خدمة: IAM ← حسابات الخدمة ← أنشئ حسابًا ← «المفاتيح» ← إضافة مفتاح ← JSON. ينزل ملف: افتحه وانسخ محتواه كله في المربع أعلاه واحفظ.
    4. في Google Analytics: الإدارة ← «إدارة الوصول إلى الخاصية» ← + ← الصق بريد حساب الخدمة (يظهر هنا بعد الحفظ) بدور «مُشاهد».
    5. في Search Console: الإعدادات ← «المستخدمون والأذونات» ← إضافة مستخدم ← البريد نفسه بإذن «كامل» (ليُرسل خريطة الموقع؛ و«مقيَّد» يكفي للقراءة).
    6. اضغط «اختبر الربط» واختر الخاصية والموقع من القائمة، ثم «حفظ الربط».
