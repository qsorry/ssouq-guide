# صفحات المتجر التعريفية (Salla)

صفحات "الشرح" القديمة على `ssouq.com` صارت بطاقة واحدة تحيل إلى الشرح الصحيح
على `guide.ssouq.com`، حتى لا تبقى نسختان من الشرح تتعارضان (كانت صفحة VAR Player
تقول "Add User / Playlist" و"Xtream Codes API"، وصفحة NEXT+ تقول رمز الخادم
`846`، والصحيح في الدليل: اختيار **Code** ورمز الخادم **`55555`**).

لوحة سلة لا تكشف هذه الصفحات عبر الـ API، فتُحدَّث يدويًا:
لوحة التحكم ← المتجر ← الصفحات التعريفية ← الصفحة ← وضع HTML (`<>`) ←
الصق محتوى الملف كاملًا بدل المحتوى القديم ← حفظ.

| الملف | الصفحة على المتجر | يحيل إلى |
|---|---|---|
| `page-1498838649-smarters-pro-android.html` | شرح تثبيت IPTV Smarters Pro على أندرويد (المرجع الذي بُنيت عليه البقية) | صفحة الشرح الكامل على المتجر `page-1472544980` |
| `page-1163326164-var-player-ios.html` | شرح تطبيق VAR Player للآيفون والآيباد | `guide.ssouq.com/iphone` |
| `page-1834650686-next-plus.html` | شرح تطبيق NEXT IPTV للآيفون (محتواها أندرويد وآيفون) | `guide.ssouq.com/android` وزر ثانٍ لـ `guide.ssouq.com/iphone` |

أيقونات التطبيقات تُحمَّل من `guide.ssouq.com/static/img/apps/` نفسها، فلا تُرفع
نسخة ثانية على سلة.
