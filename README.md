# guide.ssouq.com

صفحة إنشاء يوزرات M3U Lines (Xtream-Masters) لمتجر ssouq.com، متعددة الحسابات. تعمل عبر Coolify من الـ Dockerfile بدون أي إعداد إضافي.

## الاستخدام
1. أول مرة تفتح الرابط تظهر صفحة الإعداد: ضع كلمة مرور المدير (اسم الدخول `admin`).
2. من `/admin` أضف الحسابات. لكل حساب: اسم دخول، كلمة مرور، رابط API، مفتاح API، هوست افتراضي.
3. كل مستخدم يدخل على الصفحة الرئيسية ببياناته ويرى باقات الـ API الخاص به فقط، مع سجل وهوست منفصلين.
4. تسجيل الدخول من صفحة `/login` عادية بكوكيز، و`/logout` لتسجيل الخروج، ومن صفحة الإدارة يمكن تصدير الحسابات واستيرادها كملف JSON.

## الملفات
- `xm_lines.py` السيرفر (Python بدون مكتبات خارجية). الحسابات تُحفظ في `data/accounts.json`.
- `xm_lines.html` صفحة الإنشاء، `admin.html` الإدارة، `setup.html` الإعداد الأول، `login.html` تسجيل الدخول.

## ملاحظة عن الحفظ
ملف الحسابات داخل الحاوية في `/app/data`. يبقى عند إعادة تشغيل الحاوية، لكنه يُمسح عند إعادة البناء (أي دفع كود جديد). لحفظه دائمًا أضف Volume في Coolify على المسار `/app/data`، أو صدّر الحسابات من صفحة الإدارة واستوردها بعد إعادة البناء.

محلياً: `python xm_lines.py web` ثم افتح http://127.0.0.1:8080
